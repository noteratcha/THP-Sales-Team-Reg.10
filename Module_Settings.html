คู่มือการอัปเดตระบบ & LINE OA Webhook

คำแนะนำขั้นตอนการทำให้ใช้งานได้ (Deploy) ใหม่ และการผูกเชื่อมโยงข้อมูลกับบอท OrderBigLot

วิธีที่ 1: อัปเดตแบบไม่ต้องเปลี่ยนลิงก์ (แนะนำ ⭐)

อัปเดตเวอร์ชันผ่าน Manage Deployments

วิธีนี้สะดวกที่สุด ลิงก์ URL ของ Web App จะยังเป็นตัวเดิมเสมอ ทำให้ไม่ต้องเข้าไปแก้ไขค่า Webhook ใน LINE Console

  1. ใน Google Apps Script กดปุ่ม Deploy (การทำให้ใช้งานได้) -> เลือก Manage deployments (จัดการการทำให้ใช้งานได้)
  2. คลิกรูป ดินสอ (แก้ไข / Edit) ที่ชื่อสคริปต์หลักของคุณ
  3. ที่เมนูย่อย Version ให้เลือกเปลี่ยนเป็น "New version" (เวอร์ชันใหม่)
  4. กดปุ่ม Deploy ด้านล่างเพื่ออัปเดตระบบ
ลิงก์เดิมใช้งานต่อได้ทันที ไม่ต้องตั้งค่าใน LINE ใหม่!
วิธีที่ 2: สร้างการจำหน่ายใหม่ (New Deployment)

กรณีที่คุณกดปุ่ม "New deployment" (การทำให้ใช้งานได้ใหม่) แทนการแก้ไขตัวเดิม:

การกด New deployment จะทำให้ Google สร้าง ลิงก์ URL ตัวใหม่ขึ้นมา ซึ่งหากใช้วิธีนี้ คุณจะต้องทำสิ่งนี้เพิ่มครับ:

  1. คัดลอก URL เว็บแอปตัวใหม่ ที่ได้มา
  2. ไปที่ LINE Developers Console -> บอท "OrderBigLot" -> แท็บ Messaging API
  3. ไปที่หัวข้อ Webhook settings -> กด Edit (แก้ไข) และนำ URL ตัวใหม่ไปวางแทนของเดิม แล้วกดบันทึก
  4. จากนั้นพิมพ์ .id ในกลุ่มอีกครั้ง เพื่อเชื่อมต่อใหม่อีกรอบครับ
ต้องนำลิงก์ URL ใหม่ไปเปลี่ยนใน LINE Developers Console เสมอ!
